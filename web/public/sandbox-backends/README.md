# Sandbox backend brand assets

These SVGs are the projects' own logo files, unchanged, so the console does not
depend on third-party icon packs or runtime network requests. Each belongs to
its project and is used here only to identify that sandbox backend.

- `firecracker.svg`: `docs/images/fc_logo_icon.svg` from
  `firecracker-microvm/firecracker` (Apache-2.0).
- `microsandbox.svg`: `docs/logo/light.svg` from `zerocore-ai/microsandbox`
  (Apache-2.0). It is the full lockup (mark plus wordmark); the console shows
  only the mark by clipping the image, not by editing the file.
- Docker uses `../presets/docker.svg`, the Docker mark already shipped for the
  Docker preset.
